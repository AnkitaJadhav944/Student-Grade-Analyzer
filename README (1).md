# Student Grade Analyzer Using Python

## Project overview
A beginner-friendly Python application that accepts a student's name and marks in five subjects, calculates total and average marks, assigns a grade, and reports PASS or FAIL.

## Features
- Accepts a student name and marks for five subjects
- Validates marks so they must be numbers from 0 to 100
- Calculates total and average marks
- Assigns a grade using conditional statements
- Reports PASS only when every subject mark is at least 35
- Displays a subject-wise performance report

## Tools
- Python 3
- Google Colab (browser-based) or any Python editor

## Python concepts used
Variables, strings, numbers, conditionals, loops, functions, lists, dictionaries, exception handling, and the built-in `sum()` and `all()` functions.

## How to run
### Google Colab
1. Open https://colab.research.google.com/
2. Choose **File → Upload notebook** and upload `Student_Grade_Analyzer.ipynb`.
3. Run the notebook cells from top to bottom.
4. In the interactive program cell, enter a name and marks when prompted.

### Python on a computer
Run:
```bash
python student_grade_analyzer.py
```

## Grading rules used
- A+: 90–100
- A: 80–89.99
- B: 70–79.99
- C: 60–69.99
- D: 50–59.99
- F: below 50
- PASS: every subject mark is 35 or above; otherwise FAIL.
